## 📝 Developer Note (Task 1 & Task 2)

My goal across Task 1 and Task 2 was to craft a real-world, high-performance web experience for TechBridge by Baselink Services Limited. For Task 2, I expanded the site by building a dedicated Programs experience (`programs.html`) that cleanly answers *"What exactly can I learn at TechBridge?"*. I visually differentiated the two core tracks: **Data Analytics** (*working with data and extracting actionable insights*) and **Web Development** (*designing and building websites & web applications*). I incorporated a comprehensive syllabus breakdown for each track featuring skills like Spreadsheet Analysis, Data Cleaning, SQL, Visualization, Business Analytics, HTML5, CSS3, JavaScript, Git/GitHub, and Web Project Building. The entire site operates on 100% pure HTML5 and CSS3—achieving interactive mobile drawer navigation via CSS checkbox selectors and accessible FAQ accordions using native HTML5 `<details>` and `<summary>` elements without any JavaScript dependencies.
