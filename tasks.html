Task 01 Day 1

Build the TechBridge Homepage

Beginner
+

Create the first version of the TechBridge website using structured HTML5 and CSS3 to establish the organization's online presence.

HTML5 Structure CSS3 Layouts Brand Identity Responsive Viewports

🎯 Key Milestone & Deliverables:

  • Header with TechBridge logo, tagline, and navigation bar.
  • Hero banner introducing TechBridge by Baselink Services Limited.
  • Cards introducing Data Analytics and Web Development tracks.
  • Footer with official contact email: techbridgebaslink@gmail.com.
Task 02 Day 4

Build the TechBridge Programs Experience

Beginner → Intermediate
+

Create a dedicated Programs experience (`programs.html`) that presents TechBridge's available learning programs clearly to prospective interns.

Multipage Routing Program Differentiation Syllabus Breakdown Glassmorphic Cards

🎯 Key Milestone & Deliverables:

  • Differentiate Data Analytics (*Data & Insights*) vs Web Development (*Web & Apps*).
  • Detailed syllabus for Spreadsheet Analysis, Data Cleaning, SQL, HTML, CSS, and Git.
  • Official application CTA button linking to Google Form.
  • Interconnected navigation linking back to `index.html`.
Task 03 Day 8

Build the Internship Tasks Experience

Intermediate
+

Create an interface (`tasks.html`) that presents the 8 TechBridge internship tasks and helps users understand the complete 30-day learning journey.

Curriculum Mapping Sequence Timeline Difficulty Tiers Pure HTML5 Details

🎯 Key Milestone & Deliverables:

  • Display all 8 tasks with Day numbers, titles, and descriptions.
  • Visual progression indicators from Day 1 to Day 26.
  • Difficulty progression badges (*Beginner* to *Advanced Capstone*).
  • Seamless navigation connecting Home, Programs, Tasks, and Apply pages.
Task 04 Day 11

Build an Interactive Task Tracker

Intermediate
+

Use JavaScript DOM manipulation to make the internship task experience interactive, allowing interns to mark completion and track their progress.

JavaScript DOM Event Handlers Progress State LocalStorage API

🎯 Key Milestone & Deliverables:

  • Interactive checkboxes to toggle task completion status.
  • Dynamic progress bar updating completion percentage (e.g. 3/8 Tasks Done).
  • Task filtering by difficulty tier or release status.
  • Persistent progress state saved in browser LocalStorage.
Task 05 Day 15

Build the Intern Registration Experience

Intermediate → Advanced
+

Create a professional registration and onboarding interface for TechBridge interns to sign up, select their track, and create their profile.

Form Controls Field Validations User Onboarding State Capture

🎯 Key Milestone & Deliverables:

  • Input fields for Intern Name, Email, Preferred Track, and Experience Level.
  • Real-time client-side form validation error indicators.
  • Onboarding confirmation step with cohort details.
  • Clean user profile creation state.
Task 06 Day 19

Build the Task Submission System

Intermediate → Advanced
+

Create an interface through which interns can prepare, review, and submit their completed task work (GitHub Repository URL & Live Demo URL).

Submission Form URL Validation Developer Notes Receipt Verification

🎯 Key Milestone & Deliverables:

  • Task selection dropdown linked to active tasks.
  • URL validation for GitHub Repo and Live Web Deployment links.
  • Developer note text area (3-5 sentences summarizing project learnings).
  • Submission receipt dialog confirming successful upload.
Task 07 Day 22

Build the Intern Dashboard

Advanced
+

Create a comprehensive dashboard where an intern can view their profile details, overall completion progress, task history, and submission statuses.

Dashboard Layout Metric Cards Submission History Progress Analytics

🎯 Key Milestone & Deliverables:

  • Intern profile summary widget with track status.
  • Stat metrics: Total Tasks Submitted, Completion Percentage, Recommendation Eligibility.
  • Submission history table displaying submitted tasks and reviewer notes.
  • Quick action buttons for submitting next available tasks.
Task 08 Day 26

Build the Complete TechBridge Platform

Advanced Capstone
+

Combine the different components created during the 30-day internship into a complete, unified, and production-ready TechBridge Internship Platform.

System Integration End-to-End Routing Unified State Capstone Launch

🎯 Key Milestone & Deliverables:

  • Seamless integration of Home, Programs, Tasks, Tracker, Registration, Submission, and Dashboard.
  • Full cross-browser and mobile responsive testing.
  • Production bundle deployment to GitHub Pages or Netlify.
  • Final evaluation for Baselink Services Limited Recommendation Letter.
